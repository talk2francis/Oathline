# Oathline brand assets

The official identity is the folded Oathline mark paired with the OATHLINE wordmark. Source PNGs live in [`brand-assets/`](../brand-assets/). Website-ready aliases live in `site/public/brand/`.

## Usage map

| Role | Asset |
| --- | --- |
| Dark interface navigation and footer | `site/public/brand/oathline-lockup-dark.png` |
| Light documents and repository surfaces | `site/public/brand/oathline-lockup-light.png` |
| Dark-interface mark | `site/public/brand/oathline-mark-dark.png` |
| Light-interface mark | `site/public/brand/oathline-mark-light.png` |
| Social/Open Graph preview | `site/public/brand/oathline-social.png` |
| Browser favicon | `site/app/icon.svg`, a compact vector rendering of the official mark |

## Rules

- Preserve the mark’s proportions and the spacing between mark and wordmark.
- Use the light artwork on `#0A0A0B` or another near-black surface.
- Use the dark artwork on `#F4F1E8` or another warm document surface.
- Keep the brass token `#B8942F` as an accent; the logo itself remains monochrome.
- Do not add glow, gradients, Binance yellow, shield imagery or robot imagery.
- Do not present the two brand mockups as screenshots of shipped Oathline functionality. They are visual concept references.
- Product evidence remains the ruling document, receipt chain and reconciliation output; brand artwork never substitutes for proof.
