# Oathline — 90-second narration master

Target delivery: calm, precise, technically literate; approximately 126 words per minute with deliberate visual pauses. Avoid announcer energy.

## Script

**00:00–00:05**  
An agent can hold permission to trade. That does not mean every trade should pass.

**00:05–00:13**  
Binance Agent OS keeps authentication in its official OAuth connection. Oathline adds a separate, expiring boundary on how that authority may be used.

**00:13–00:22**  
This signed mandate permits BNBUSDT Spot, with fifteen dollars per order, forty dollars per day, and state no older than thirty seconds.

**00:22–00:31**  
Now untrusted context pushes the agent toward an eighty-three-dollar market order. Oathline does not guess why the reasoning failed. It evaluates the action.

**00:31–00:42**  
Eighty-three forty exceeds fifteen per order—and eighty-three forty exceeds the entire daily limit. Outside mandate. Binance submission: not called.

**00:42–00:50**  
In this observed Codex 0.153.3 run, the host honored that denial before `spot.newOrder` was submitted.

**00:50–01:04**  
A valid seven-dollar order takes the other path—but only with current evidence. Oathline first withholds it on stale state. A fresh Binance read arrives. The same action now passes, and Binance fills it.

**01:04–01:13**  
Order 12534006821: real BNBUSDT, matched back to the authorization that preceded it.

**01:13–01:23**  
The full chain verifies locally: thirty-six entries, zero broken links. Reconciliation reports one matched execution, zero orphans, zero divergences.

**01:23–01:30**  
Policy before execution. Evidence after. Oathline gives software a boundary.

## Pronunciation and performance

- Say “BNB U-S-D-T,” not “binance dollar pair.”
- Read `spot.newOrder` as “spot dot new order.”
- Read the order ID in grouped cadence: “twelve five-three-four, zero-zero six-eight, two-one,” or omit spoken digits if the delivery becomes unnatural; the ID remains on screen.
- Leave a half-beat after “Outside mandate” and after “not called.”
- The strongest vocal emphasis belongs on “real BNBUSDT” and “matched back,” not on the threat setup.
